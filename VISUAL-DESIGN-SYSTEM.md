# TrustRadar Visual Design System — alpha.6

## Direction
A vivid, modern intelligence workspace with a broad but disciplined color vocabulary. The product uses a deep navy foundation, electric blue/cyan for primary interaction, orange for brand emphasis, violet for selected analytical categories, and green/red/amber for meaningful states. Color is paired with labels and icons; it is never the only carrier of meaning.

## Verification boundary
This alpha applies the new palette to the existing interface and adds a Simplified Chinese locale foundation for navigation/settings. Chinese translations are not yet complete across all screens, dialogs, validation messages and reports. Icon replacement, font embedding/CJK font verification, rendered visual QA, accessibility contrast audit, H5/Android builds and device testing remain open.
